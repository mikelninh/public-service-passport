# Public Service Passport — Impact + Commercial Metrics

The citizen product should optimise for useful access; the institutional business should optimise for measurable delivery improvement.

## Citizen metrics

- supported journey completion;
- time to understand the next useful action;
- repeated evidence requests avoided;
- official-link handoff completion;
- correction/complaint rate;
- accessibility/mobile completion;
- false reassurance / misleading-result reports.

## Institutional metrics

- preflight exception detection before manual review;
- source-verified coverage;
- authority manual touches per case;
- repeat evidence requests;
- structured-case integration cost;
- proof/receipt verification success;
- maintained rule/policy update effort.

## Revenue boundary

Institutional revenue should rise because delivery becomes easier, safer and more maintainable — not because citizens disclose more, receive less support, or need a paid tier to understand their rights.
